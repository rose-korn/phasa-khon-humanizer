# ภาษาคน (Phasa Khon Humanizer)

[Read in English](README.md)

ภาษาคนคือ Agent Skill ที่ช่วยเขียนข้อความ **ภาษาไทย** และ **ภาษาอังกฤษ** ที่อ่านแล้วรู้ว่า AI เขียน ให้กลับมาอ่านเหมือนคนเขียน โดยไม่เปลี่ยนเนื้อหาและไม่แต่งข้อมูลเพิ่ม ใช้ได้กับ Claude Code, Claude.ai, Codex, Cursor และ agent อื่นที่รองรับ skill

เป้าหมายคือให้คนอ่านแล้วรู้สึกเป็นธรรมชาติ ไม่ได้มีไว้หลบ AI detector

## ตัวอย่าง

**ก่อน:**
> ทางบริษัทฯ มีความยินดีเป็นอย่างยิ่งที่จะขอแจ้งให้ทราบว่า ระบบลางานออนไลน์ใหม่ได้ถูกพัฒนาขึ้นเพื่อยกระดับประสิทธิภาพในการบริหารจัดการทรัพยากรบุคคลขององค์กรได้อย่างมีประสิทธิภาพและยั่งยืน ซึ่งถือเป็นก้าวสำคัญในการขับเคลื่อนองค์กรสู่ยุคดิจิทัล
>
> ทั้งนี้ พนักงานสามารถทำการยื่นใบลาผ่านระบบได้ตั้งแต่วันที่ 1 พฤศจิกายน 2569 เป็นต้นไป ...

**หลัง:**
> ตั้งแต่วันที่ 1 พฤศจิกายน 2569 พนักงานยื่นใบลาผ่านระบบลางานออนไลน์ได้ บริษัทฯ จะเลิกใช้แบบฟอร์มกระดาษในวันที่ 30 พฤศจิกายน 2569 สอบถามเพิ่มเติมได้ที่ฝ่ายบุคคล ต่อ 204

ตัวอย่างเต็มอยู่ใน [examples/](examples/)

## สัญญาณ AI ภาษาไทยที่ skill นี้จับ

- **ภาษาแปล** เช่น "ถูกพัฒนาขึ้น" "มันช่วยให้คุณ..." "ทำการ/มีการ" หน้ากริยา "เมื่อพูดถึง..."
- **เปิดและปิดแบบสำเร็จรูป** เช่น "ในยุคปัจจุบัน..." "ปฏิเสธไม่ได้ว่า..." "กล่าวโดยสรุป" "บอกเลยว่าห้ามพลาด!"
- **คำเชื่อมขึ้นต้นทุกย่อหน้า** เช่น "นอกจากนี้" "อย่างไรก็ตาม" "ดังนั้น"
- **คำขยายติดท้าย** เช่น "ได้อย่างมีประสิทธิภาพ" "อย่างยั่งยืน"
- **คำลงท้ายและระดับภาษา** เช่น ครับ/ค่ะ ทุกประโยค "นะคะ" ในประกาศทางการ ภาษาทางการปนภาษาพูด
- **การพิมพ์** เช่น ขีดยาวและจุลภาคแบบอังกฤษในเนื้อความไทย วงเล็บภาษาอังกฤษตามหลังทุกศัพท์

ทั้งหมด 28 รูปแบบ ดูรายการเต็มได้ใน [references/patterns-th.md](references/patterns-th.md)

การเขียนไทยปนศัพท์อังกฤษเป็นเรื่องปกติ skill จะไม่แก้ส่วนนี้ และจะเก็บคำลงท้าย ครับ หรือ ค่ะ ของผู้เขียนไว้ตามเดิม

## ติดตั้ง

### Claude Code

```text
/plugin marketplace add Pisitkorn-Bootchada/phasa-khon-humanizer
/plugin install phasa-khon-humanizer@phasa-khon-humanizer
```

### Codex, Cursor, Gemini CLI และ agent อื่น

```bash
npx skills add Pisitkorn-Bootchada/phasa-khon-humanizer --global --agent '*'
```

### Claude.ai และ Claude Desktop

ดาวน์โหลด repo เป็น ZIP (**Code → Download ZIP**) แล้วอัปโหลดเป็น skill ในหน้า Settings

## วิธีใช้

```
/phasa-khon-humanizer

[วางข้อความ]
```

หรือพิมพ์บอกตรงๆ ก็ได้ เช่น "ช่วยเขียนข้อความนี้ใหม่ให้อ่านเหมือนคนเขียน" หรือ "แคปชันนี้อ่านแล้วเหมือน AI ไหม"

ถ้าอยากให้ออกมาเป็นสำนวนของตัวเอง แนบตัวอย่างงานเขียนของคุณสัก 2-3 ย่อหน้าไปด้วย skill จะเลียนความยาวประโยค คำลงท้าย ศัพท์อังกฤษ และเครื่องหมายวรรคตอนที่คุณใช้

ถ้าไม่มีตัวอย่าง ข้อความไทยจะคงระดับภาษาเดิมไว้ และถ้าบอกไม่ได้ว่าเป็นระดับไหน จะใช้ภาษาเขียนกึ่งทางการ ไม่มีคำลงท้าย

## ใช้อย่างรับผิดชอบ

skill นี้แก้แค่สำนวน ไม่ได้ตรวจข้อเท็จจริง และไม่ได้ทำให้ข้อความ "ตรวจไม่เจอ"

- **คุณรับผิดชอบสิ่งที่คุณเผยแพร่เอง** skill เก็บทุกข้อความอ้างจากต้นฉบับไว้ รวมถึงข้อที่ AI แต่งขึ้นเอง แล้วทำรายการให้คุณตรวจ ตรวจให้ครบก่อนเผยแพร่
- **ทำตามกฎของที่ที่คุณส่งงาน** สถานศึกษา วารสาร นายจ้าง และแพลตฟอร์มหลายแห่งกำหนดให้แจ้งว่าใช้ AI หรือห้ามใช้ skill นี้ไม่ได้เปลี่ยนกฎเหล่านั้น อย่าใช้เพื่อปิดบังการใช้ AI ในที่ที่ต้องแจ้ง
- **ไม่รับประกันผล** คนอ่านหรือเครื่องมือตรวจ AI อาจยังมองว่าเป็นข้อความจาก AI ซอฟต์แวร์นี้ให้ใช้ "ตามสภาพ" โดยไม่มีการรับประกัน ดู [LICENSE](LICENSE)
- **ไม่เก็บข้อมูล** skill เป็นแค่ชุดคำสั่งให้ agent ของคุณ ไม่ได้ส่งข้อมูลไปไหนเอง ข้อความของคุณไปถึงแค่บริการ AI ที่คุณใช้อยู่แล้ว ตามเงื่อนไขของบริการนั้น

## ร่วมพัฒนา

เจอสัญญาณ AI ภาษาไทยที่ยังไม่มีในรายการ เปิด issue พร้อมตัวอย่างจริงและฉบับแก้ได้เลย ก่อนส่ง pull request ให้รัน `python3 scripts/validate-package.py` การส่ง pull request ถือว่าคุณยอมให้งานที่ส่งมาเผยแพร่ภายใต้สัญญาอนุญาต MIT ของโปรเจกต์นี้ ใช้เฉพาะตัวอย่างที่คุณเขียนเองหรือมีสิทธิ์นำมาเผยแพร่ และลบข้อมูลส่วนบุคคลออกก่อน

## เครดิต

โครงสร้าง skill ขั้นตอนการทำงาน และรูปแบบภาษาอังกฤษหลายข้อ ดัดแปลงมาจาก [Humanizer](https://github.com/blader/humanizer) ของ Siqi Chen (MIT) ซึ่งอ้างอิงหน้า [Signs of AI writing](https://en.wikipedia.org/wiki/Wikipedia:Signs_of_AI_writing) ของ Wikipedia ส่วนรูปแบบภาษาไทยและภาษาผสมเขียนขึ้นใหม่สำหรับโปรเจกต์นี้ ดู [LICENSE](LICENSE)

โปรเจกต์นี้ทำขึ้นเองโดยอิสระ ไม่มีส่วนเกี่ยวข้องและไม่ได้รับการรับรองจากผู้สร้าง Humanizer, Wikipedia หรือบริษัท AI ใดๆ ชื่อผลิตภัณฑ์ เช่น Claude, ChatGPT, Gemini และ Cursor เป็นเครื่องหมายการค้าของเจ้าของ ใช้ในที่นี้เพื่อบอกว่าใช้ร่วมกันได้และเพื่ออ้างถึงข้อมูลทดสอบเท่านั้น
