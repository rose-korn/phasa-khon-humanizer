# Real AI samples

Unedited answers from ChatGPT, Claude, and Gemini (October 2026) to the prompts below, copied from each chat app and converted from Word to plain text. Each section starts with the prompt it answers. Some files include chat-app leftovers such as connector prompts and suggestion chips; they are kept because removing them is part of the job (TH-26).

Prompts used: Facebook trip post, Instagram café caption, sunscreen sales post, email asking to move a deadline, Q3 sales summary, Slack update in mixed Thai and English.

Use these to check new patterns against real output and to test the skill by hand. Do not edit them.
